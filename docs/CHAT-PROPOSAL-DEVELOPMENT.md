# 대화형 연구계획서 초안 경로: 개발 기록

## 목표와 피드백

ROK의 초기 목표는 공부·연구·문헌·영상 작업을 파일 해시와 사람의 승인으로 연결하는 것이었다. 공개 저장소의 AGENTS.md와 README도 주로 전체 실행 흐름과 설치·CLI를 설명했다. 그러나 처음 방문한 연구자가 **새 주제를 말한 뒤 무엇을 질문받고 언제 초안 파일을 받는지**는 첫 화면에서 확인하기 어려웠다.

공개된 [6주차 Padlet 과제 안내](https://padlet.com/limtaehyeong/6-s0247iczf8dctni5jaf5)의 범용 AGENTS.md 호출 취지와 대조해, 첫 사용 장면을 별도의 대화형 초안 경로로 명시했다. 이 문서는 과제 적합성 검토 기록이며 평가자의 점수를 예측하지 않는다.

| 구분 | 이전 | 이번 변경 |
|---|---|---|
| AGENTS.md 시작 | 역할·전체 파이프라인 중심 | 새 아이디어 → 핵심 조건 확인 → 방향 비교 → 연구자 선택 → Markdown 초안 |
| README 첫 화면 | 영상·설계 설명 뒤 설치와 `rok new` | Codex에서 폴더를 열어 바로 요청하는 문장과 두 시연 링크 |
| 초안과 전체 실행 | 같은 설명에서 이어짐 | 대화형 초안에서 멈출 수 있음을 명시; 수집·검증은 선택한 후속 경로 |
| 범용성 증거 | 내부 합성 워크플로 테스트 3종 | 서로 다른 질문·자료·분석을 쓰는 공개 대화 예제 2종 추가 |

## 두 주제에 적용하며 확인한 점

1. [교육 질적 사례](../examples/chat-proposal/education-qualitative/README.md)는 학생의 사용 효과를 임의로 상정하지 않고, 가상 연구자의 선택에 따라 **교사 지도 경험**으로 범위를 좁혔다. 성인 교사 면담·공개 안내문과 주제분석을 연결하고 학생 직접 조사·결과 주장은 제외했다.
2. [보건 양적 사례](../examples/chat-proposal/health-quantitative/README.md)는 **관련성**과 개입 효과를 구분한 뒤, 가상 연구자의 선택에 따라 익명 횡단면 설문과 회귀분석 후보를 연결했다. 척도·모집처·표본 규모는 미정으로 두었다.
3. 두 초안 모두 확인한 문헌이 없으므로 연구 공백이나 인용을 확정하지 않았다. 답변 전에 참여자·표본·방법을 결정하지 않는다는 AGENTS.md 규칙을 대화 예제에 반영했다.

두 대화는 **사전에 선택을 명시한 합성 시연 대본**이다. 계획서 파일은 실제 저장소 산출물이지만, 별도 사용자 시험이나 Codex·Claude 자동 실행의 성공 기록은 아니다. 전체 실행 엔진의 기능·테스트는 [평가 문서](EVALUATION.md)에서 별도로 확인한다.

## 재현과 다음 검증

새 Codex 대화에서 저장소를 열어 README의 문장을 입력하고, 실제로 접근 가능한 자료와 제출 조건을 답한다. 에이전트가 질문을 최대 3개씩 묶어 묻는지, 답변 뒤 `workspace/<주제>/proposal-draft.md`를 생성하는지, 연구문제–자료–분석·윤리와 미확인 근거가 일치하는지 연구자가 [자가평가표](CHAT-SELF-EVALUATION.md)로 점검한다. 다른 전공 주제 반복은 선택 사항이다.
## 실제 사용자 선택을 반영한 후속 시연 (2026-10-13)

한 사용자가 초임 남교사의 젠더적 교직사회화와 초임교사의 수면 부족을 연구 아이디어로 제시했다. 에이전트는 공개 예시의 방법과 초점, 두 계획서의 형식을 묶어 세 가지 선택을 물었고, 사용자는 가상 면담 연구·수면시간과 교직 적응의 관련성·JQI와 APA 7을 선택했다. 이에 따라 [두 주제의 대화 요약과 Markdown 초안](../examples/chat-proposal/live-two-topics-2026-10-13/README.md)을 생성했다. 개인 경험이나 기존 연구 원고는 공개 초안에 사용하지 않았다.

이것은 실제 채팅에서 받은 선택을 반영한 **대화형 초안 작성 기록**이다. 전체 원대화 로그, 별도 새 채팅에서의 파일 저장 성공, CLI 전체 실행의 성공 기록은 아니다. 참여자 모집, 원출처 문헌, 측정 척도와 제출 서식은 미확인으로 남겼다.
## 독립 재현과 평가 준비

2026-10-13 새 체크아웃 두 건에서 실제 Codex CLI 대화를 이어 보냈다. 두 주제 모두 첫 턴에서 핵심 질문을 하고 답변 뒤 초안 텍스트를 만들었으나, 실행 호스트의 읽기 전용 정책 때문에 파일 저장에는 실패했다. [독립 재현 기록](CHAT-REPRODUCTION-2026-10-13.md)에 실패 단계와 판정 기준을 공개했다. 이는 앞 절의 사용자 대화 기반 파일 산출물과 다른 시험이다. 독립 파일 생성은 아직 통과하지 않았으며 연구자가 [자가평가표](CHAT-SELF-EVALUATION.md)로 실제 산출물을 확인할 수 있다.
