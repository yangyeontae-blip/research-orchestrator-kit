# 실제 대화 선택을 반영한 두 주제 시연

이 사례는 2026-10-13 한 사용자가 두 연구 아이디어를 제시하고, 에이전트의 세 질문에 직접 답한 뒤 작성한 **대화형 계획서 초안**이다. 앞서 공개된 `education-qualitative`·`health-quantitative`의 사전 작성 합성 대본과 구분한다. 공개 기록에는 개인 연구 원고·경험·학교·참여자·원문을 넣지 않았다. 질문과 선택은 아래처럼 익명화해 요약했으며 원대화의 전체 로그라고 주장하지 않는다.

| 주제 입력 | 실제 확인 질문 | 사용자가 고른 방향 | 출력 |
|---|---|---|---|
| 초임 남교사의 젠더적 교직사회화 | 기존 자문화기술지 방향 또는 공개 시연용 가상 면담 연구? | 가상 면담 연구 | [JQI 지향 초안](gendered-socialization-jqi-draft.md) |
| 초임교사의 수면 부족 | 수면시간·교직 적응의 관련성 또는 질적 경험 탐색? | 수면시간과 교직 적응의 관련성 | [APA 7 지향 초안](sleep-adjustment-apa7-draft.md) |
| 두 주제 공통 | 계획서 형식은 JQI+APA 7 또는 둘 다 범용? | 첫째 JQI, 둘째 APA 7 | 각 초안에 형식 선택 반영 |

첫 사례는 면담 자료와 해석적 분석, 둘째는 자기보고 수면시간·교직 적응 측정과 관련성 분석으로 이어진다. 두 연구 모두 실제 참여자, 수집 자료, 결과, 확인된 선행연구가 아직 없다. 따라서 초안은 **연구 설계 제안**이며 출처 대조, 기관·학회 형식 검증, 윤리 검토, 자료 접근 확인을 마친 제출본이 아니다. 이 시연은 대화→초안의 작동 사례이며 CLI 전체 파이프라인이나 외부 연구자 사용성 검증의 성공 증거는 아니다.

## 재현 방법

1. 저장소를 Codex에서 열고 `AGENTS.md`를 따르도록 요청하며 새로운 연구 주제 한 줄을 입력한다.
2. 에이전트의 핵심 질문(최대 3개)에 연구자가 직접 답한다.
3. 에이전트가 합의한 연구문제–자료–분석과 미확인 사항을 담은 Markdown 초안을 생성하는지 확인한다.

이 저장소의 실제 사용자 자료 없이 다른 주제로도 같은 과정을 시험할 수 있다. 공개 초안의 가상 설계 선택을 실제 연구자의 답변이나 확보된 표본으로 오해하지 않는다.
