# 출처 지도

이 영상은 저장소 자체 기능만 설명한다.

- `README.md`: 제품 범위, 다섯 역할, 세 관문, 9.5점 주장 제한
- `docs/ARCHITECTURE.md`: 상태와 승인 결합 구조
- `docs/CLI-REFERENCE.md`: 사용자 명령
- `AGENTS.md`: 역할별 권한과 사실 창작 금지
- `tests/*.test.mjs`: 해시 무효화, 재개, PDF, 클라우드, 영상 관문 검증 범위

실제 연구 결과·사례·참여자·논문 본문을 사용하지 않았다. 화면의 연구 주제는 기능 설명을 위한 일반 문구다.
