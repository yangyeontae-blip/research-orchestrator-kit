# 대화형 계획서 초안 시연

이 두 사례는 **가상의 연구자 선택을 미리 정한 합성 대화**입니다. 실제 사용자의 발언 기록이나 자동 CLI 실행 로그가 아닙니다. 두 Markdown 계획서 파일은 저장소에 실제로 들어 있으며, 같은 `AGENTS.md`의 기본 대화 경로를 서로 다른 분야에 적용한 결과 예시입니다.

| 주제 | 토론에서 정한 자료 | 방법 | 산출물 |
|---|---|---|---|
| 초등학생의 생성형 AI 활용을 둘러싼 교사의 지도 경험 | 성인 교사 면담, 공개된 학교 안내문 | 질적 주제분석 | [교육 연구 초안](education-qualitative/proposal-draft.md) |
| 성인의 건강정보 이해도와 건강검진 예약 의향 | 익명 설문 | 횡단면 양적 연구 | [보건 연구 초안](health-quantitative/proposal-draft.md) |

각 폴더의 README에는 입력 문장, 에이전트의 확인 질문, 가상 연구자의 선택, 그 선택을 계획서에 반영한 위치를 기록했습니다. 실제 사용에서는 **연구자가 답하기 전**에 대상·표본·방법을 확정하지 않습니다. 예제의 일정·모집 가능성·측정 도구는 검증되지 않은 설계 후보이며 연구 결과가 아닙니다.

### 확인 방법

1. 저장소를 Codex에서 열고 각 폴더의 첫 요청 문장을 입력합니다.
2. 자신의 실제 접근 가능 자료와 제출 조건을 답합니다. 예제 답변을 그대로 복사할 필요가 없습니다.
3. 답변 뒤 생성된 `workspace/<주제>/proposal-draft.md`에서 연구문제–자료–분석–윤리의 대응, 미정·미확인 표시를 확인합니다.
4. 문헌 수집과 근거 검증을 원할 때에만 ROK 전체 실행으로 넘어갑니다.
