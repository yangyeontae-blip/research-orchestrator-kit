# 실제 호출 기록과 지침 개선 과정

이 폴더는 `AGENTS.md`를 Codex에서 실제로 호출한 기록을 담습니다. 대화는 지어내지 않고 실제 세션에서 가져온 것만 싣습니다.

## 개선 과정 (AGENTS.md 버전)

| 버전 | 내용 | 계기 |
|---|---|---|
| v0 (0.7.0까지) | 파일과 해시로 인계하는 개발·운영 규칙(다섯 역할, 승인 관문, CLI 목록). 새 아이디어가 왔을 때 무엇부터 할지는 없었음 | 도구로서는 충실했지만 "호출하면 논의한 뒤 계획서를 낸다"는 에이전트의 모습이 파일에 없었음 |
| v1 (0.7.1) | 맨 앞에 "A. 호출 규칙"을 추가: 핵심 조건 확인 → 방향 토론 → 연구문제·방법 합의 → 초안, 그리고 8개 항목 자체 점검. 기존 규칙은 "B. 심화 모드"로 내림. 모델·추론 강도는 `.codex/config.toml`에 고정 | 주제에 종속되지 않고 대화로 시작하는 범용 에이전트가 되도록 |
| v2 이후 | 아래 두 세션에서 드러난 문제를 고친 내용을 여기에 적는다 | (세션 뒤 기록) |

## 시험 시나리오 (서로 다른 분야·방법)

같은 `AGENTS.md`, 같은 첫 문장으로 시작합니다. 주제와 답변은 사용자가 직접 정합니다.

| | 세션 1 | 세션 2 |
|---|---|---|
| 분야 | 교육 | 보건 |
| 기본 방법 | 질적 연구 | 양적 연구 |
| 첫 요청 | 이 저장소의 AGENTS.md에 따라, 초등학생의 생성형 AI 활용에 관한 연구 아이디어를 저와 논의한 뒤 연구계획서 초안을 작성해 줘. | 이 저장소의 AGENTS.md에 따라, 성인의 수면 부족과 건강 지표에 관한 연구 아이디어를 저와 논의한 뒤 연구계획서 초안을 작성해 줘. |

## 세션마다 남길 것

각 세션은 `docs/demos/session-N-<주제>.md` 하나로 둡니다.

1. **입력 주제**: 첫 요청 문장 그대로.
2. **대화 요약**: 에이전트가 물은 질문, 제시한 방향 안, 사용자가 고른 것(실제 대화에서 짧게 발췌).
3. **토론에서 결정한 사항**: 연구 유형, 형식, 연구문제, 방법, 대상.
4. **출력 파일**: 생성된 `proposals/*.md`(원문 또는 링크).
5. **점검 결과**: 에이전트가 보고한 7개 자체 점검, 그리고 사람이 읽고 발견한 문제.
6. **고친 점**: 문제가 있었다면 `AGENTS.md`를 어떻게 바꿨는지(위 표에 버전 추가).

실제 학교·학생·연구 참여자의 이름은 넣지 않습니다.
