# 자산 및 권리

- 나레이션: Microsoft Edge Korean Neural TTS (`ko-KR-SunHiNeural`), MoneyPrinterTurbo가 지원하는 Edge TTS 방식으로 생성. 사용자 요청에 따라 삽입.
- 배경음: FFmpeg `sine` 소스로 만든 짧은 합성 앰비언트 톤. 외부 음악·샘플 없음.
- 그래픽: Remotion/React 직접 제작. 외부 이미지·로고·논문 본문 없음.
- 워크플로 참조: MoneyPrinterTurbo, MIT, https://github.com/harry0703/MoneyPrinterTurbo
- 사용 목적: 대본→TTS→문장 자막→낮은 볼륨 BGM→MP4 합성의 구현 패턴만 참조했으며, 해당 프로젝트 코드를 복제하거나 포함하지 않음.
