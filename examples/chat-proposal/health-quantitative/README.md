# 합성 대화 2: 보건 분야 양적 연구

**시연 성격:** 실제 참여자·설문 응답·효과 추정치가 없는 가상의 사용자 선택입니다. 아래는 반복 가능한 대화 대본이며 실제 사용자 대화 로그라고 주장하지 않습니다.

**첫 요청:** “이 저장소의 AGENTS.md에 따라, 성인의 건강정보 이해도와 건강검진 예약 의향에 관한 연구 아이디어를 저와 논의한 뒤 연구계획서 초안을 작성해 줘.”

**에이전트의 확인 질문**
1. 알고 싶은 것은 두 변수의 관련성인가요, 특정 안내 프로그램의 효과인가요?
2. 접근 가능한 자료는 익명 설문, 기관의 기존 기록, 또는 다른 자료인가요?
3. 연구 대상 범위와 제출 형식·마감은 정해졌나요?

**가상 연구자의 선택:** “프로그램 효과가 아니라 관련성을 알고 싶습니다. 기관 기록에는 접근할 수 없으니 익명 설문을 계획해 주세요. 성인 지역 주민을 대상으로 하되 모집처는 미정입니다. generic 형식, 마감 미정입니다.”

**방향 합의:** 한 시점의 익명 설문으로 관련성을 분석한다. 건강검진 예약 **실제 행동이나 인과 효과를 주장하지 않는다**. 설문 도구와 표본 규모는 근거를 확인한 뒤 정한다.

**출력:** [proposal-draft.md](proposal-draft.md). 두 연구문제 모두 설문 변수와 회귀분석 후보에 대응한다. 교사 면담과 주제분석을 쓰는 교육 사례와 질문·자료·분석 방식이 다르다.
