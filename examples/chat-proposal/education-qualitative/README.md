# 합성 대화 1: 교육 분야 질적 연구

**시연 성격:** 실제 학생·학교·교사에 대한 자료가 없는 가상의 사용자 선택입니다. 아래는 반복 가능한 대화 대본이며 실제 사용자 대화 로그라고 주장하지 않습니다.

**첫 요청:** “이 저장소의 AGENTS.md에 따라, 초등학생의 생성형 AI 활용에 관한 연구 아이디어를 저와 논의한 뒤 연구계획서 초안을 작성해 줘.”

**에이전트의 확인 질문**
1. 학생의 사용 경험 자체를 연구할까요, 아니면 이를 지도하는 교사의 판단과 경험을 연구할까요?
2. 실제로 접근 가능한 자료는 무엇인가요(예: 교사 면담, 수업 기록, 공개 안내문)?
3. 제출 형식이나 마감이 정해져 있나요?

**가상 연구자의 선택:** “교사의 지도 경험을 다루겠습니다. 성인 교사 면담과 공개된 학교 안내문을 검토할 수 있다고 가정해 주세요. 아직 특정 학교나 참여자는 확보하지 않았습니다. 형식은 generic, 마감은 미정입니다.”

**방향 합의:** 학생 개인의 사용 효과를 측정하거나 학생을 직접 조사하지 않는다. 교사들이 활용 가능성과 위험을 어떻게 판단하고 지도 방침을 구성하는지 질적으로 탐색한다. 면담 가능성은 아직 검증되지 않았다.

**출력:** [proposal-draft.md](proposal-draft.md). 연구문제 1·2는 교사 면담과 연결되고, 연구문제 3은 공개 안내문과 면담을 함께 대조한다. 선행연구와 연구 공백은 원출처 미확인으로 남긴다.
