# 외부 사용자 평가

v0.2는 자동 검사 통과만으로 “9.5점 연구도우미”라고 주장하지 않는다. 다음 평가가 실제로 끝나야 공개 문구를 바꿀 수 있다.

## 대상과 방법

- 대학원 연구자 또는 연구방법 검토자 최소 3명
- 익명화된 동일 합성 사례의 v0.1과 v0.2 결과를 순서를 무작위로 제시
- 사용성, 근거 추적성, 방법 정합성, 안전성, 문서 완성도를 각각 0–10점으로 평가
- 평가자별 자유 의견과 중대한 오류를 함께 기록

## 통과 기준

- 전체 평균 9.5 이상
- 다섯 항목 각각의 평균이 9.0 이상
- 합성 사례의 인용–참고문헌 불일치 0건
- 공개 이력 개인정보 문제 0건
- 모든 핵심 주장에 근거 상태 표시
