# v0.2 합성 사례

모든 인물·기관·문헌은 도구 검증용으로 만든 가상 자료다. 실제 연구 결과나 실제 출판물을 나타내지 않는다.

- `apa7-autoethnography`: 질적 1인 자문화기술지, APA 7 학생 원고
- `jqi-interview`: 질적 면담 연구, JQI 프로필
- `generic-quantitative`: 범용 양적 연구, 공통 정합성 검사

`node examples/synthetic-v2/run-demo.mjs`는 세 사례의 표준 JSON을 검증하고 Markdown에서 DOCX와 문서 매니페스트를 생성한다. 생성물은 Git에서 제외된 임시 작업 폴더에만 둔다.
