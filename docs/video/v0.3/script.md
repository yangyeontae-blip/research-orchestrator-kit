# Research Orchestrator Kit v0.3 소개 영상 대본

형식: 약 90초, 16:9, 한국어 TTS·문장 자막·직접 제작 모션그래픽

[계획서의 제안] 이 영상은 완료된 연구 결과가 아니라 도구가 연구계획서를 다루는 흐름을 설명한다.

1. 흩어진 아이디어·문헌·계획서가 서로 다른 버전을 가리키면 근거가 끊긴다.
2. `rok new`에서 연구 아이디어와 APA 7·JQI·범용 형식을 선택한다.
3. 공부·연구·문헌·영상 에이전트가 같은 SHA-256 상태를 확인한다.
4. 사용 권한이 있는 PDF·HWP·HWPX는 로컬에서 읽고, 근거 상태를 구분한다.
5. 수집·반영·영상은 사람이 승인한 정확한 해시에서만 진행된다.
6. Markdown은 원본이고 DOCX·HWPX는 다시 만들 수 있는 파생 문서다.
7. 자동화는 연구자의 판단을 대신하지 않으며, 주장을 원문·파싱·메타데이터 상태로 투명하게 남긴다.
