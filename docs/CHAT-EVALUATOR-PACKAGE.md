# 외부 평가자를 위한 대화형 계획서 시험 패키지

이 양식은 ROK를 처음 쓰는 대학원 연구자 또는 연구방법 검토자 **최소 3명**이 독립적으로 평가하도록 준비한 것이다. 아직 평가자가 정해지지 않았으며 점수·후기·실행 성공을 미리 채우지 않는다.

## 시작

1. [ROK 저장소](https://github.com/yangyeontae-blip/research-orchestrator-kit)를 새 폴더에 복제하거나 내려받아 Codex에서 **쓰기 가능한 폴더**로 연다. 설치·CLI 명령 없이 대화형 초안 경로를 시험한다.
2. 저장소의 `AGENTS.md`에 따라 아래 둘 중 하나를 연구자와 논의한 뒤 계획서 초안을 작성해 달라고 요청한다. 실제 사람·학교·건강 기록은 제공하지 않는다.
   - 사례 A: “초임 남교사의 젠더적 교직사회화” — 질적 연구 방향을 선택하되 학교급·참여자·자료 확보 상태를 임의로 확정하지 않는다.
   - 사례 B: “초임교사의 수면시간과 교직 적응의 관련성” — 양적 관찰 연구 방향을 선택하되 인과관계·표본·척도를 지어내지 않는다.
3. 평가자 본인이 하나의 **새 주제 C**를 골라 같은 지침으로 반복한다. 주제 C는 기존 예시와 다른 분야가 권장된다.
4. 첫 질문을 받은 뒤 필요한 선택을 직접 답한다. 질문 문구, 답변, 생성 파일의 존재와 내용을 기록한다.

## 성공 판정

각 사례에서 다음을 직접 확인한다. 설명을 읽어야만 가능한 조작이 있으면 기록한다.

- 첫 턴에서 이미 제공된 정보는 재질문하지 않고 핵심 질문을 최대 3개로 묶는가?
- 연구자 답변 전에 방법·표본·결과를 확정하지 않는가?
- 답변 후 연구문제–자료–분석이 대응하고 윤리·실행 제약을 표시하는가?
- 문헌을 확인하지 않았다면 근거 미확인으로 표시하는가?
- `workspace/<주제>/proposal-draft.md`가 **실제 생성**되고 열리는가? 채팅에 초안만 나타났다면 실패로 기록한다.
- 개인정보가 포함되지 않으며 초안과 검증 완료본을 구분하는가?

## 평가 기록 양식 — 평가자마다 복사

- 평가자 코드(실명 불필요):
- 평가 날짜와 Codex/운영체제 버전:
- 저장소 커밋 SHA:
- 시험 주제(A/B/C)와 연구자가 고른 방향:
- 첫 질문 수와 불필요하게 다시 물은 항목:
- 초안 파일 실제 경로 및 생성 여부(예/아니오):
- 연구문제–자료–분석 불일치 또는 만들어낸 사실:
- 걸린 시간 및 막힌 단계:
- 사용성(0–10), 근거 추적성(0–10), 방법 정합성(0–10), 안전성(0–10), 문서 완성도(0–10):
- 가장 먼저 고쳐야 할 한 가지:

평가 기록에는 실제 참여자 정보나 비공개 문헌 원문을 붙이지 않는다. 세 평가자의 기록을 모은 뒤 평균과 최저 항목을 계산하며, 평가 전에는 ‘9.5점 달성’이나 ‘1등’을 주장하지 않는다. 파일 저장을 못 한 실행은 별도 성공으로 계산하지 않는다.
