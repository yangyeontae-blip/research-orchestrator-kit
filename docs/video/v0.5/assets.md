# 자산 및 권리

- 그래픽: Remotion/React로 직접 만든 모션 그래픽. 외부 이미지, 로고, 논문 본문 없음.
- 화면 속 파일명, 해시, 주장, 쪽수: 모두 합성 예시. 실제 연구자료나 실제 문헌이 아님.
- 나레이션: Microsoft Edge Korean Neural TTS (`ko-KR-HyunsuMultilingualNeural`), `edge-tts` CLI로 생성.
- 배경음과 효과음: FFmpeg `aevalsrc`·`anoisesrc`로 합성한 사인파 패드, 차임, 저음, 노이즈 스윕. 외부 음악이나 샘플 없음.
- 글꼴: Noto Sans KR, JetBrains Mono (SIL Open Font License 1.1), `@remotion/google-fonts`로 렌더링 시 불러옴.
- 렌더링: Remotion 4.0.534. Remotion은 개인과 소규모 팀에 무료인 자체 라이선스를 따름 (https://www.remotion.dev/license).
- 영상은 도구의 상태 처리 방식을 설명할 뿐이며, 계획의 예상 기여를 완료된 연구 결과처럼 말하지 않음.
